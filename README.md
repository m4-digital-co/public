# M4 Digital · Public downloads

Public, no-login download host for M4 Digital app builds (source repos stay private).
APKs are published here automatically by CI as **rolling "latest" releases** — each
app has a fixed tag whose asset is overwritten every build, so the download URL is stable.

## IPTV TV (Android TV)

**Always-latest APK:**
```
https://github.com/m4-digital-co/public/releases/download/iptv-tv-latest/iptv-tv.apk
```
Download page: https://m4-digital-co.github.io/public/

Install on the TV via the **Downloader** app / a browser (enter the URL), or
`adb install -r iptv-tv.apk`. The IPTV TV app's **Settings → Update app** also points here.
