Link format

Generate links on your server.

Have a customer portal? Build a personal link per customer. A link is just your playlist settings, packed into the URL. Nothing is stored or looked up, so there’s no API to call.

1. Pack the settings as compact JSON

KeyMeaning
t"m3u" or "xt" (Xtream Codes). Required.
nName shown in the app.
uM3U playlist URL. Required for m3u.
eXMLTV guide URL (plain or .gz).
h, s, pXtream server, username, password. h and s required for xt; leave p out to have the customer enter it.
oXtream stream format: "ts" (default) or "m3u8".
aUser-Agent header, if your service needs one.
rRefresh interval in minutes. Default 7 days.

2. Encode it as a token

UTF-8 bytes, base64url without padding, prefixed with IPTV1.

3. Wrap it in a link

Web link (use this)https://m4-digital-co.github.io/public/iptv/open.html#add=<token>
App deep linkiptv://add?c=<token>

The web link opens the app when it’s installed and offers the web player when it isn’t. The token sits after #, so it never reaches a server log.

Examples

// JavaScript (browser or Node 16+)
function iptvLink(settings) {
  const json = JSON.stringify(settings);
  const b64 = btoa(String.fromCharCode(...new TextEncoder().encode(json)))
    .replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
  return 'https://m4-digital-co.github.io/public/iptv/open.html#add=IPTV1.' + b64;
}

iptvLink({ t: 'm3u', n: 'My TV', u: 'https://example.com/get.php?user=alice&token=abc' });
<?php // PHP
function iptv_link(array $settings): string {
  $b64 = rtrim(strtr(base64_encode(json_encode($settings, JSON_UNESCAPED_SLASHES)), '+/', '-_'), '=');
  return 'https://m4-digital-co.github.io/public/iptv/open.html#add=IPTV1.' . $b64;
}

echo iptv_link(['t' => 'xt', 'n' => 'My TV', 'h' => 'http://example.com:8080', 's' => 'alice']);
# Python
import base64, json

def iptv_link(settings):
    raw = json.dumps(settings, separators=(",", ":")).encode()
    return "https://m4-digital-co.github.io/public/iptv/open.html#add=IPTV1." + base64.urlsafe_b64encode(raw).decode().rstrip("=")

Keep credentials safe

  • Anyone with a plain link can read what’s in it. Only publish links that are safe to be public.
  • For personal logins, send each customer their own link, leave the password out, or use a passphrase (build those here or in the app).
  • Passphrase links (IPTV1E.) are AES-256-GCM with a scrypt-derived key. The app and this page create them; there’s no need to build them yourself.
